# FinanIA 💚

MVP de um aplicativo de organização de finanças pessoais com uma experiência de assistente inteligente, criado como desafio de projeto de Vibe Coding.

## Problema
Controlar finanças manualmente pode ser cansativo e os números, sozinhos, nem sempre ajudam a decidir o próximo passo.

## Solução
O FinanIA reúne receitas, despesas, saldo, taxa de economia e metas em um dashboard simples. Um copiloto conversacional analisa os dados cadastrados e responde perguntas sobre gastos e capacidade de economia.

## MVP
- Dashboard financeiro responsivo
- Cadastro e exclusão de receitas/despesas
- Categorias
- Cálculo automático de saldo e taxa de economia
- Meta financeira e estimativa de prazo
- FinanIA Copilot com conversas simuladas baseadas nos dados locais
- Dados somente no navegador durante a sessão; sem banco e sem autenticação

> O Copilot deste MVP é uma simulação determinística para demonstrar o fluxo de um agente de IA sem exigir API paga. Uma evolução futura pode integrar um modelo de linguagem no backend.

## Tecnologias
React, TypeScript, Vite, CSS responsivo e Lucide Icons.

## Executar
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```

## Processo de Vibe Coding
1. Definição do problema e do público.
2. Criação de um PRD simplificado.
3. Refinamento do escopo para um MVP demonstrável.
4. Implementação conversacional com IA.
5. Teste do fluxo e avaliação crítica do resultado.

## Entrega do desafio
Além do código, a pasta `docs` contém PRD, prompt final e reflexão. A pasta `screenshots` pode receber os prints das interações e do projeto em execução antes do envio ao GitHub.

## Aviso
Projeto educacional. Não realiza movimentações financeiras nem fornece aconselhamento financeiro profissional.
