# Prompt final do projeto

Crie um MVP chamado **FinanIA**, um aplicativo responsivo de organização de finanças pessoais com experiência de copiloto inteligente.

O problema é que o controle financeiro manual é cansativo e os usuários frequentemente registram números sem saber como transformá-los em decisões. A solução deve reunir receitas, despesas, saldo, taxa de economia e meta financeira em um dashboard simples e permitir perguntas em linguagem natural.

O MVP deve ter: dashboard com quatro indicadores; cadastro de receitas e despesas com descrição, valor, tipo e categoria; lista de movimentações; exclusão de registros; meta financeira editável; barra de progresso; estimativa de meses para alcançar a meta; e um chat chamado FinanIA Copilot capaz de responder, com base exclusivamente nos dados registrados, perguntas como “Onde estou gastando mais?” e “Como está minha meta de economia?”.

Não implemente autenticação, banco de dados, integração bancária, Open Finance, pagamentos ou investimentos. Para tornar a demonstração gratuita, o copiloto pode simular o comportamento de um agente usando regras determinísticas sobre os dados locais. Não invente valores ou transações.

Use React, TypeScript e Vite. O visual deve ser moderno, profissional, mobile-first, em dark mode, com verde como cor de destaque, tipografia limpa, cards discretos, ícones Lucide e boa hierarquia visual. Evite excesso de elementos e priorize uma experiência direta ao ponto.

O projeto deve ser executável com `npm install` e `npm run dev`, ter build de produção com `npm run build` e incluir README explicando problema, solução, funcionalidades, tecnologias, execução, processo de Vibe Coding, limitações e possíveis evoluções.
